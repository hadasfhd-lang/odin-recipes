# Odin Recipes

A collection of simple Indonesian recipes, including nasi goreng, mie ayam, and ayam geprek.

## Recipes

- [Nasi Goreng Jawa](nasgor.html)
- [Mie Ayam](mieayam.html)
- [Ayam Geprek](ayamgeprek.html)

## Run the project

Open [index.html](index.html) directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Project structure

- `index.html` — recipe index page
- `nasgor.html` — Nasi Goreng Jawa recipe
- `mieayam.html` — Mie Ayam recipe
- `ayamgeprek.html` — Ayam Geprek recipe
